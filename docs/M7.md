# M7 — Composition Director

M7 introduces a formal layer above Reawarp's existing event generators. It remains an offline-first mathematical audio laboratory, not a DAW or a live event sequencer.

## M7.0 — Formal trajectories
Five seeded structures are provided: evolving, additive, subtractive, episodic, and drift. Section transitions are allocated in 4/4 bars; the final audio buffer still ends at the exact requested duration. Section plans retain independent energy, density, brightness, instability, space, layer activation, and motif treatment values.

## M7.1 — Section-aware material
Section roles provide a first composition-level guide for anchor presence, density, melody participation and register. The current motif labels are not a full motif object model or transformation graph.

## M7.2 — Layer variation
A layer can be regenerated against a frozen base project. Independent random streams for sample overlays keep them separate from their procedural equivalents. The regenerated stem and its event lane are replaced; unrelated stem buffers are preserved.

## M7.3 — Desktop workbench
The desktop workspaces will be refined into a darker Form/Voices/Rhythm Generator, a Library browser, shared ELI LAB branding/icon, and optional tray controls.

## IDM constraints
Preserve an identifiable reference, make deviations purposeful, use subtraction and silence, distinguish energy from loudness, and retain clear orchestration. Higher event count is not the definition of greater complexity.
