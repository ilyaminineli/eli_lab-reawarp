# M7 — Composition Director, Long-Form Generation, and Desktop Workflow

Status: first composition-aware rendering increment.

## 1. Why M7 follows M6

The Field Guide describes IDM as a relationship between stable reference points and controlled change, not simply maximum rhythmic density. The Advanced Composition Appendix formalises a hierarchy:

1. Event.
2. Pattern.
3. Phrase.
4. Section.
5. Composition.

M7 adds a section director above the existing event generators. It decides the formal situation and macro targets; specialised generators continue to create local events and sound buffers.

## 2. Formal trajectories

| Structure | Formal behaviour |
|---|---|
| `evolving` | Intro, foundation, expansion, mutation, reassembly, outro |
| `additive` | Accumulation toward a peak, then release |
| `subtractive` | Full opening gradually exposes and dissolves material |
| `episodic` | Contrasting scenes, suspension, and return |
| `drift` | Related states with gradual, bounded changes |

Section durations vary deterministically within bounded limits. Boundaries are contiguous, and the final section ends at the exact requested duration.

## 3. Section plan

Each section records exact time boundaries, energy, density, brightness, instability, spatial openness, role activation, motif treatment, register guidance, and a phrase-length hint. The plan is stored in `project.json` metadata as `composition_plan`.

## 4. Renderer behaviour

- Kick anchors are removed in intro, suspension, and outro-like sections.
- Supporting snare and hat activity is thinned in sparse sections.
- Melody event contours are retained, while selected sections may omit the line or shift its register.
- Noise texture follows section activation and density.
- Ambience follows the section's spatial openness.
- Imported break triggers are suppressed in selected sparse states.
- The section plan uses its own deterministic random stream, so changing a stem does not change unrelated arrangement decisions.

This first increment uses role activation and density gates. It is not yet a full motif planner or counterpoint system.

## 5. Duration and variation

GenerationConfig, CLI, and GUI accept 5–45 seconds. Fixed-time rendering still produces exactly `round(duration * sample_rate)` frames. This does not yet provide a bar-count duration mode.

Composition-level variation changes section weights and bounded macro/register perturbations. It is not a global probability for extra hits. Break-specific phrase variation remains a separate lower-level control.

Energy, density, brightness, instability, and space are separate values. Energy does not map to master gain.

## 6. Desktop changes

The desktop app exposes formal structure, energy, variation, and 45-second duration controls; groups Generator controls into Composition, Sound, and Break pages; adds a local Library workspace; and provides a Reawarp window/tray icon with Show and Quit actions. The tray behaviour is conditional on the operating system exposing a tray host.

## 7. M6 sample tag repair

New standalone samples receive conservative semantic categories from filename and folder tokens. Existing databases can run `reawarp-library retag` to add those categories to already-indexed samples. These tags are heuristics, not a replacement for explicit user tagging.

## 8. Comparison with the IDM guides

| Principle | Current state |
|---|---|
| Independent deterministic random streams | Implemented for generator lanes; section decisions use a separate named stream |
| Stable pulse and controlled deviations | Partial: existing sixteenth-grid grammars plus section suppression |
| Event/pattern/phrase/section hierarchy | Partial: event generators and section plans exist; phrase generation is not yet a general object model |
| Long-form pacing | First increment: five formal structures |
| Energy distinct from loudness | Macro values are separate; energy is not master gain |
| Motif continuity through transformations | Partial: existing geometric melody, register changes, and motif state labels |
| Counterpoint and independent cycle relationships | Not yet a general planner |
| Candidate generation, scoring, audition, and freeze | Not yet implemented |
| Score automation rendered over time | Not yet connected to the offline renderer |
| Full formal closure / motif dissolution | Partial: role reduction exists, but no complete motif decay planner |

## 9. Follow-on work

1. **M7.1 — Motif objects:** identity across rhythm, contour, duration, articulation, register, timbre, and space; transformation operators.
2. **M7.2 — Phrase candidates:** hard constraints, continuity/novelty/groove scoring, audition, and freeze.
3. **M7.3 — Automation and clocks:** connect score lanes to phrase/section macro curves while preserving separate beat, sample, wall, and UI clocks.
4. **M7.4 — Composition editor:** section map, macro curves, motif inspector, candidate comparison, and library integration.

M7 is a principled start, not a claim that every composition concept in the Appendix is complete.
