# M5.1 — Sound Design and Rhythmic Break Integrity

Status: implemented in the deterministic NumPy renderer.

M5.1 refines the sound palette and fixes the rhythmic model for break-based material. The goal is not maximum event density or indiscriminate glitching. A stable reference groove is the coordinate system that makes local disruption readable.

## 1. Break rhythm grammar

The former break lane rolled independent probabilities on every sixteenth-note slot, then chose a drum voice and pan independently. That produced unstable density and no durable motif.

The replacement uses four explicit 16-step grammars:

- `broken_funk`: kick/snare anchors with selected syncopated support.
- `half_time`: a wider backbeat with restrained secondary events.
- `straight`: regular anchors and even eighth-note support.
- `sparse`: strong anchors with very limited ornamentation.

The first four structural accents are preserved. Density selects four to eight ranked events per bar; it does not turn every step into another probability roll. Event times remain on the sixteenth-note grid.

Phrase variation is applied only at the configured 1-, 2-, or 4-bar cycle boundary. Its value is a real probability of mutating the phrase (zero means no changes; one means every cycle boundary changes). One local operation may move a secondary event by one sixteenth, remove an ornament, or add one quiet offbeat event; high settings may permit a second edit. Anchors are never displaced or removed. The same seed and settings produce the same phrase mutations.

### Controls

| Setting | Range | Purpose |
|---|---:|---|
| Break style | broken_funk / half_time / straight / sparse / auto | Selects the phrase grammar |
| Density | 0–1 | Selects four to eight events per bar |
| Phrase variation | 0–1 | Controls local phrase-end mutations and velocity spread |
| Cycle bars | 1 / 2 / 4 | Sets how often a phrase may change |

The other kick, snare, and hat generators retain their independent rhythmic streams. This break grammar only controls the synthetic break and the imported break-sample trigger score.

## 2. Imported break playback

An imported `break` sample is no longer played in full at every break event. Reawarp now:

1. Applies the chosen non-destructive transform chain.
2. Detects transients and builds ordered, non-overlapping source slices.
3. Falls back to an even slice grid for smooth material with no detected transients.
4. Maps 16-step rhythm slots to slices across the source's estimated bar count.
5. Triggers only the selected slice, using a short edge fade and the event's velocity/pan.
6. Trims the slice to the next trigger onset, preventing the imported stem from accumulating overlapping tails.

This prevents the previous full-clip pile-up. The same source phrase maps consistently from bar to bar; phrase mutations can select a neighbouring slice by changing the event slot.

The slice selection, source frame range, rendered frame count, overlap-trim status, transform list, and source hash are stored with each sample-trigger event and project manifest. Source files remain untouched.

## 3. Coherent sample transformations

The high-level pipeline is deliberately less destructive by default:

- Slice rearrangement keeps the first slice and performs one local adjacent swap.
- Dropout removes at most one sixteenth-note cell per bar, quantized to the project BPM.
- Stutter remains a beat-sized opening-region repeat.
- Reverse, pitch shift, time stretch, gate, granular, and spectral freeze remain explicit effects for deliberate use.

The lower-level transform functions remain available for callers who want full random slice permutations or free block dropout. The production pipeline chooses controlled operations.

## 4. Melody voices

The previous melody voice was a short carrier/FM oscillator with fixed partials. M5.1 adds five profile-driven additive/FM timbres:

- `soft_keys`
- `glass_bell`
- `soft_pluck`
- `reed_pad`
- `wood_mallet`

Each voice defines its partial ratios and weights, attack/decay/sustain/release, FM ratio and depth, unison detuning, low-pass cutoff, and soft saturation. Partial frequencies above the safe Nyquist margin are omitted. The automatic profile is selected once per generated melody lane, not independently for every note, so the line has a coherent instrumental identity.

## 5. Harmonic ambience

The optional `ambience` stem is a slow, deterministic harmonic bed. It combines a restrained partial cloud with a low root anchor derived from the project seed (independent of the melody lane), spectrally softened noise, slow gain drift, stereo motion, and a few low-level early reflections. It is separate from `noise_texture`, so a project can use both or disable either.

Ambience has an independent random stream and may be regenerated without changing the melody, percussion, or other stems. Its level is exposed in the Python API, CLI, and desktop generator.

## 6. Softer automatic percussion choices

The complete percussion profile catalogues remain available. Automatic mode now favours restrained profiles (for example, soft-round/deep-sub kicks, acoustic/tonal snares, and closed/dark hats). It selects once per lane (and once per break voice type), so the instrument character stays coherent across the phrase instead of changing on every hit. More aggressive industrial, distorted, hard-click, and digital voices remain available as explicit choices instead of appearing unexpectedly in an automatic render. Automatic melody selection likewise favours soft keys, soft pluck, reed pad, and wood mallet; glass bell remains an explicit choice.

## 7. Command line examples

A restrained, syncopated break:

```powershell
reawarp --break-style broken_funk --break-density 0.45 --break-variation 0.25 --break-cycle-bars 2 --seed 211 --output output/break-study
```

A slower ambient palette:

```powershell
reawarp --melody-profile reed_pad --ambience-level 0.18 --break-style sparse --break-density 0.25 --break-variation 0.15 --output output/ambient-study
```

Turn off the ambient stem:

```powershell
reawarp --no-ambience --output output/dry-study
```

## 8. Boundaries and next milestone

M5.1 remains an offline renderer. It does not add real-time synthesis, plug-in hosting, a piano roll, or a general-purpose arrangement timeline.

M6 implements the searchable local stem/sample library, audio descriptors, similarity ranking, collections, and project-variation genealogy. See [M6.md](M6.md).
