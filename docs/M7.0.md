# M7.0 — Formal Composition Director

**Implemented:** deterministic formal trajectories above the existing event/pattern generators.

Five structures are available: evolving, additive, subtractive, episodic, and drift. Section durations are allocated in 4/4 bars when possible; very short renders compact the structure to the available bar count. The final section ends at the exact requested render duration, so the audio buffer retains the requested frame count.

Each section stores independent energy, density, brightness, instability, space, layer-activation flags, a motif-treatment label, register guidance, and bar boundaries. The plan is deterministic from the root seed.

CLI example:

    reawarp --duration 45 --structure episodic --energy 0.72 --variation 0.8 --seed 211 --output output/m7

Energy is not output gain. Structural variation is not a hit-probability control.
