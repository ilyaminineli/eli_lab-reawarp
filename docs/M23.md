# M23 — Variation browser and critical-listening workflow

**Status:** Planned  
**Depends on:** M14 test/benchmark foundation, M15 stem regeneration, M17 Score provenance, M22 preview/export consistency.

## Goal

Make generation an iterative selection process while preserving determinism and user intent.

## Philosophy

The guides describe candidate generation, listening, subtraction, invariance and context tests. Analysis is a tool for asking questions, not a replacement for taste.

## Scope

- Batch-generate comparable stem, role-pair, sample-bank, automation and sound-object variations.
- Preserve a frozen base project and store per-candidate seed overrides, changed parameters and ancestry.
- Provide matched-level A/B audition; optionally hide candidate labels before selection.
- Add waveform and spectrogram difference views for dry, processed, send, return and master.
- Allow keep, discard, promote, branch and restore without mutating source assets.
- Add listening sets: full mix, isolated roles, role pairs, transitions, opening/middle/ending and subtraction variants.
- Produce a compact listening report with technical flags and user-authored notes; never auto-grade artistic quality.
- Connect candidate/source identity to the local audio library and project genealogy.

## Acceptance criteria

- Each candidate can be recreated from saved config and seed lineage.
- Unchanged stems remain bit-identical where independent regeneration promises that contract.
- A/B audition is level-matched and leaves the frozen base unchanged.
- Candidate ancestry, notes and selection survive project export/reload.
- Worker cancellation, candidate selection and recovery are covered by UI tests.

## Listening protocol

Compare candidate sets before reading changed parameters when practical. Select based on identity, development, role clarity, negative space and context—not loudness or event count.

## Deliverables

- Candidate model and variation batch service.
- Matched-level audition and comparison UI.
- Waveform/spectrogram comparison and listening-set presets.
- Project and library genealogy integration.
