## Musical purpose and distinctions

Cross-synthesis lets one sound contribute spectral or rhythmic identity while another supplies the audible material. Frequency transformation changes the internal relationships of partials. These tools suit hybrid IDM sources: a vocal or machine recording can articulate a synth, while a harmonic source can become metallic or inharmonic.

The module deliberately separates four techniques. Ring modulation is a time-domain product; fixed-Hz frequency shift translates partials by a constant offset; spectral-envelope transfer applies a smoothed spectral shape while retaining carrier phase; a vocoder follows modulator band envelopes to articulate carrier detail. They are not interchangeable presets.

## Independent APIs

All operations return `CrossSynthesisResult(audio, diagnostics)`; inputs must have equal frame counts and finite mono/stereo audio. A mono modulator is duplicated for a stereo carrier; a stereo modulator promotes a mono carrier to stereo. There is no automatic alignment, resampling or gain compensation.

### Ring modulation

`ring_modulate(carrier, modulator, sample_rate, *, wet=1.0, bypass=False)`

[
y[n]=(1-w)x[n]+w,x[n]m[n]
]

The product generates sum and difference sidebands. It does not perform pitch shifting or envelope transfer. The processor does not align the modulator for the caller.

### Fixed-Hz frequency shift

`frequency_shift(audio, sample_rate, shift_hz, *, wet=1.0, edge_padding_ms=20.0, bypass=False)`

An analytic-signal representation is translated by multiplying by (e^{j2pi Delta f t}) and taking the real component. This is a fixed-Hz translation, not pitch shift: harmonic intervals generally become inharmonic. Offset is bounded to ±0.45 of sample rate; edge padding is 0–250 ms. The operation has zero offline file-alignment offset after cropping the padded render, but its FFT is a whole-file operation and not a streaming implementation.

### Spectral-envelope transfer

`spectral_envelope_transfer(carrier, modulator, sample_rate, *, frame_size=1024, hop_size=256, envelope_bins=31, amount=1.0, max_ratio=8.0, wet=1.0, bypass=False)`

The modulator's frequency-smoothed magnitude envelope is divided by the carrier envelope, clamped to ([1/R,R]), and raised to `amount` (0–1). This ratio scales the complex carrier spectrum, retaining its phase and fine spectral identity. Envelope width is an odd integer 3–255; ratio ceiling is 1–32. This is envelope imprinting, not phase vocoding or an STFT vocoder.

### Band vocoder

`vocoder(carrier, modulator, sample_rate, *, bands=24, frame_size=1024, hop_size=256, attack_ms=5.0, release_ms=70.0, amount=1.0, max_band_gain=12.0, wet=1.0, bypass=False)`

Log-spaced triangular analysis bands measure carrier and modulator RMS levels. Modulator band levels pass through attack/release followers; bounded ratios control carrier spectral detail while carrier phase is retained. Band count is 4–64, attack 0–250 ms, release 0–1000 ms and maximum band gain 1–32. This is a reference band vocoder, not a formant-preserving speech engine.

## Alignment, headroom and dependencies

Sample rate is an integer of at least 1 kHz. All four operations return the carrier frame count (or input frame count for frequency shift), report zero offline file-alignment latency and reject incompatible lengths instead of silently shifting one stem. Stereo channels are processed independently with no crossfeed. No operation normalizes, limits, de-noises or auto-gains its output. Bypass and zero wet return an exact dry copy; input arrays are not mutated. Finite output and peak/RMS/headroom are recorded.

NumPy only. The spectral methods use the internal M24 STFT/WOLA reference helper. There is no SciPy, Pyo, plugin host or GPU dependency. FFT/overlap-add may vary at insignificant floating-point levels across environments; no random stream is used.

## Benchmark and listening

```bash
python scripts/benchmark_m24_3_cross_synthesis.py --duration 5 --sample-rate 48000 --output m24-3-benchmark.json
python scripts/render_m24_3_listening_example.py --output output/m24-3-cross-synthesis
```

The benchmark reports each of the four operations separately with wall time, real-time factor, traced peak memory, engine working-buffer estimate and diagnostics. The audition set writes isolated carrier and modulator files, each processed result and a JSON listening prompt. Compare at matched monitoring level, not by normalizing the engine output.
