# M7.2 — Frozen Layer Regeneration

**Implemented:** each procedural layer and imported sample overlay has its own deterministic stream group. generate_variant(..., base_project=project) creates a candidate and merges only the target stem plus its associated event lane into the base project. Unrelated stem arrays are preserved bit-identically.

Supported layers: kick, snare, hats, synthetic break, melody, noise texture, ambience, sample kick, sample snare, sample hat, and sample break.

The Stem Mixer exposes regeneration for all supported layers. Variation numbers are reproducible from the original root seed, layer name, and variation index.
