# M7.3 — Desktop Workbench and Library

**Implemented:** Generator Form/Voices/Rhythm sub-pages; initial 45-second composition control (later extended to 180 seconds in M8); darker laboratory palette; reusable UI modules under `ui/pages` and `ui/widgets`; local Library indexing, text/type/role/tag search, similarity search, named collections, and audition; packaged ELI LAB `Icon.ico`; optional tray Show/Quit actions.

The UI remains a thin controller over the offline renderer. Library indexing runs in a worker; the audio callback remains separate from disk, library, GUI, and DSP operations.

Collection creation, membership, and browsing are wired to the existing M6 API. Similarity ranking remains the documented descriptor-based heuristic, not an embedding model.

The application now exits when the main window is closed; the tray menu remains an explicit optional access point rather than changing the close action into a hidden process.

**Still future work:** editable section map and automation editor; detailed motif inspector; candidate comparison/freeze interface; and installer packaging verification on Windows.
