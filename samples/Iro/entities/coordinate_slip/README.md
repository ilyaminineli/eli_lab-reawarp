# coordinate_slip

Uneven coordinate-triggered impulses with resonant, nonuniform tails

Synthesis approach: modal_resonator_and_impulse_train

Equation: t_k=quantize(k*T*(0.35+coordinate)); y=sum_k a_k*exp(-lambda_k*(t-t_k))*sin(2*pi*f_k*(t-t_k))

Impulse trains excite multiple damped resonant modes with uneven spacing and tails.

The six variations span different registers, durations, brightness and source-feature rows.
Every WAV is deterministic from its recorded seed and source features.
