# spectral_bloom

An inharmonic partial cloud whose brightness follows the spectral field

Synthesis approach: stochastic_noise_plus_additive_partials

Equation: y=E(t)*(n*brightness+sum_j sin(2*pi*f*r_j*t+phi_j)/j); r_j in {1,1.37,2.11,3.07,4.73}

Filtered deterministic noise is mixed with a sparse inharmonic additive spectrum.

The six variations span different registers, durations, brightness and source-feature rows.
Every WAV is deterministic from its recorded seed and source features.
