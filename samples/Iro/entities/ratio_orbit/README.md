# ratio_orbit

Coupled oscillators orbiting one of the release polyrhythm ratios

Synthesis approach: rational_ratio_additive_synthesis

Equation: y=E(t)*sum_j a_j*sin(2*pi*f*(p_j/q_j)*t+phi_j); p:q in {(3,2),(4,3),(5,4),(7,4)}

Multiple oscillators follow non-integer rational relationships, not a tonal bass preset.

The six variations span different registers, durations, brightness and source-feature rows.
Every WAV is deterministic from its recorded seed and source features.
